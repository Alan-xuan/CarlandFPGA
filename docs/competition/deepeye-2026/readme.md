# 矿脉深瞳参赛规划

当前实施规范：[taskbook_v3.md](taskbook_v3.md)，排版阅读版：[deepeye_taskbook_v3.pdf](deepeye_taskbook_v3.pdf)。自动化入口见[automation_contract.md](automation_contract.md)。这批产物完成方案研究和任务书，不表示RTL、模型、ROCm或实物任务已实施或通过。

版本3依据最新已独立读回的人类赛道说明，对应AMD Ryzen AI PC＋任意AMD FPGA方向（当前指南3.2），保留传感输入和虚拟钻头范围；增加传感仪器真实量程调节作为最小物理任务候选。其赛事认定与现有8845H的ROCm实测均在R01/R02独立设门，不拿数字孪生或GPIO回采冒充机械执行。

版本1首轮候选及版本2研究稿保留历史；实施只使用版本3统一ABI和任务卡。三机首轮各五案，第二轮逐模块融合和B/C实际外评的证据在[selection_audit.md](selection_audit.md)。当前是A统筹定稿，不宣称B/C已联合签署未读的终版。
