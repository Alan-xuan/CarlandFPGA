# C 第二轮逐模块融合评析

任务 `COMP-20261013-DEEPEYE/v2`，质量主会话 Astra-C 完成。本文只追加研究结论，首轮原件不变；板测、实现、采购均为 `not_run`。输入与取证见 [sources.md](sources.md)，具体验收见 [acceptance_delta.md](acceptance_delta.md)。

## 评析正文

采用 v2 的 AMD 自主选题 3.3：真实传感、PYNQ-Z2 处理及实际反馈、PC 数字孪生构成主线。官件 3.3 要求实板输出、可复现工程、协作记录与技能包，评分为创新应用30、性能资源20、正确完整20、协作技能15、文档复现15。首轮把3.2的实体执行器、ROCm最低版本及评分套入本题，需要追加纠正；首轮历史和独立封存仍有效，不把历史修改成已经知道新规则。[S1]

保留 A 的短帧事件调度、CPU解码和低置信门控，B 的命令去重、旧会话拒绝、前视条件及业务链路隔离，C 的本地原始留存、缺失/年龄显示和盲场次评测。删去将复杂机械导向作为必交件的约束。真实探头信号进入PL；PC建议回到PL，经限幅和状态机生成实际GPIO/PWM，由独立捕获器读回驱动孪生。拔掉这条物理输出线，孪生必须停止更新并报失联。它证明硬件在环，不冒充真实钻头运动；机械台架只在核心完成后增强。

编码保留三机共同的独立块、差分Rice、RAW退化，吸收B的17位差分与长unary上界。C的误差界只对完整送达的采样点成立；摘要、降采样、缺段不能算无损曲线。公开CCSDS仅支持编码方法依据，不支持本项目固定4倍或8倍性能。PL贡献用同输入下的吞吐、延迟、资源、链路拥塞表现证明，不能以“用了FPGA”替代增益。[S5]

链路统一为共享300 baud、8N1、半双工；B的双向各300及C的8秒长窗口不直接继承。A的14字节头和两字节命令装不下B要求的命令语义，改为16字节头、32字节摘要、24字节命令和24字节状态；4秒常规80字节，加一次16字节事件及0.2秒换向共占85%，尚余18字节等价容量。常规状态同时确认命令阶段，不另藏ACK；24字节重传放下一窗，不能声称本窗必重传。首次应用、已接受、已完成分别编码；重复命令不刷新期限。正常链路队列模型通过前，撤回C原5秒响应承诺。

AI保留B的有效性掩码、观测年龄与规则基线，以C的分组盲测限制泄露，沿用A的CPU校验解码。按A最新实机证据，优先复用其8845H/32GB机械革命翼龙15Pro；HX370仅作现机模型部署失败后的替代，Max+395不列默认购买。NPU尝试固定形状INT8小CNN，CPU承担解码与控制；GPU训练/对照按实际支持启用。AMD文档支持Hawk Point的INT8 CNN，但当前NPU驱动32.0.203.240低于所取1.8安装页的最低32.0.203.280，且SDK未装，不能宣称可即用。必须保存算子分配和同输入profile。3.3下ROCm与NPU性能均是工程选择，不是资格否决项。[S2–S4]

FORCE支持岩性研究及编码回放，不能产生含水层/断层真值；台架只标“风险代理、正常、观测不足”。按整井及整次采集分割，量化校准只用训练集；公开数据、台架和合成数据分开报。采用C原始/传输后任务下降与B事件级误报计数，并增设未见噪声、饱和、断链测试；不让评价真值或PS原始档案进入在线AI。[S6]

三周交付优先级为可重复硬件链、可解释增益、模型增强、展示美化。预算按已有板卡外的传感/捕获/电源线材分档，PC单列，均待实时报价；不把预算估算当已获设备。A负责冻结公共接口与实板，B负责RTL/黄金，C负责数据、模型和独立验收。每步依赖满足由agent自动执行、定位错误并重测受影响项；接线、本人认证和未授权付款才交人类最小操作卡。接入A独占的automation_contract，不另建执行合同。

任务书新增四项硬交付：版本匹配的实测证据、可复用PYNQ技能包、协作纠错记录、冷启动复现；删掉机械任务成功率作为核心门槛，替换为硬件输出读回与孪生一致性。保留机械方案作扩展时才验避障成功与制动距离。原C评分权重与指定研究权重不同，三机研究分也不等于官分，不能据分数直接选冠军。当前结论来自本质量主会话实际阅读与复核，未把传输ACK或尚未返回的评审计作完成。

## 最终推荐配置

PYNQ-Z2保留已验证板镜像；四路3.3V数字侧ADC（MCP3204类12位器件可行，必须标实际有效位数）、两路光学/电压风险代理输入、GPIO/PWM捕获器及有线PC。捕获器只把实际输出送给孪生显示，不给AI增加高速传感通路。PC首选A已拥有的MECHREVO Yilong15Pro：Ryzen7 8845H、32GB、Radeon780M、Win11 Home build26200；磁盘余量另查，不假定1TB。CPU先打通，NPU经独立驱动/SDK门槛和INT8 CNN实际部署后启用；780M的ROCm路径未由本轮证明，不做默认依赖。替代机才选HX370/32GB/1TB。执行器、复杂三维、AI调codec均为后续增强，不强制大模型。[S3、S10]

物料规划额度（人民币，非报价、非采购授权）：已有兼容PC的最小档300–800；含独立捕获、较好传感与备用供电的推荐档800–1800；机械增强另加1500–3500。PC单列询价，先检查可借设备；任何采购前由agent给具体SKU、供货期、含税总价及替代项。核心截止：10月15接口与资源，17日黄金/真实I/O读回，21日FPGA核心，23日模型，26日集成，30日消融，11月2日复现材料，11月4日12时内部冻结，18时提交以A核验通知及后台为准。
