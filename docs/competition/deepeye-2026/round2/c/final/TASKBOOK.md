# 矿脉深瞳：C 定稿任务书

## 1. 成果与边界

按人类确认的 AMD Ryzen AI PC + 任意 AMD FPGA 方向自主选题编制。用桌面真实传感展示随钻感知中的低带宽信息取舍、风险代理判断与反馈。传感电压不能被称为水害、煤层或断层真值；数字孪生中的位置、轨迹和钻进距离都是模型状态，不是实际钻头测量。

必交链路：传感器 → PYNQ-Z2 PL 采样/时间戳/质量标记 → 独立块编码与事件调度 → 实际限速链路 → PC 严格解码/小模型 → 有期限的受限命令 → PL 状态机/实际数字输出 → 独立捕获 → 孪生。PS 保存原始记录，禁止将原始档案或评价真值旁路给在线 AI。每次演示同时呈现线字节、队列、GAP、数据年龄、置信度和真实输出状态。

选择理由：C1 的事件优先保留，C4 的 RAW 退化和本地档案保证不可压缩数据也能运行，C3 的 CPU 解码/小模型/拒识保障可解释性。C2 完整渐进码和 C5 压缩感知不进关键路径。机械导向、高端新机、大模型及漂亮动画均不阻塞核心。现有资源优先，避免把未证实的 NPU 加速当作完成条件。第二轮模块比较见 [review_v2.md](../review_v2.md)，本目录冻结其未定部分。

## 2. 平台和物料

PC 首选 A 已报告的 MECHREVO 翼龙15Pro、Ryzen 7 8845H、32GB、Radeon 780M、Windows 11。这是引用 A 的资源证据，不是 C 当前远程实测。部署前由 A 重新确认磁盘余量和软件版本。CPU 先完整贯通；NPU 选固定形状 INT8 CNN 路线。AMD Ryzen AI 1.8 官方表支持 Hawk Point 的 INT8 CNN；本轮重读安装页要求驱动至少 32.0.203.280，A 既有报告为 32.0.203.240，SDK 尚未验证。通用 quicktest 说明针对 Strix 或更新平台，不能拿它在 8845H 失败就判硬件不可用。实际项目模型编译、算子归属和推理结果才是门槛。[AMD 发布说明](https://ryzenai.docs.amd.com/en/latest/relnotes.html)、[安装说明](https://ryzenai.docs.amd.com/en/latest/inst.html)。

不用 NPU 解压任意码流。不把 780M 的 ROCm 支持当既成事实；本任务也不依赖 ROCm 特定版本。NPU 无收益时如实报告 CPU 基线，仍在 Ryzen AI PC 上完成模型推理。只有既有机器经一次有界适配仍无法完成项目必需功能，才提交 HX370/32GB/1TB 的具体替代报价；本轮不下单。

## 3. 数据、PL 和 PC

默认4路×100Hz采样，时钟目标100MHz，单主时钟加使能；异步输入用同步器/合法采样，复位同步释放。100Hz 是桌面方案参数，不是赛事或井下规格。PL 完成采样编号、窗口统计、独立块差分 Rice/RAW、事件锁存、UART 调度、命令去重和有期限输出；PS 管档案与非关键管理。每个32样本/通道块包含首值、有效位数、k、样本数及边界；17位有符号差分/无符号映射防极值溢出，长 unary 提前退出走 RAW。编码/解码必须有独立实现，不能只凭同一库往返自证。

在线基础摘要按 [PROTOCOL.md](PROTOCOL.md) 每4秒一次，以未压缩最大32字节为容量上界；可压缩摘要实际走 Rice，不可压缩走 RAW。满速原始数据6400 bit/s留在PS；不宣称压缩8倍便可实时穿过300 baud。报告原始容器、有效12位打包、载荷、含帧头线上字节四个口径；独立比较采样减少、摘要损失和熵编码收益。

PC 分三个进程：业务进程只读慢链路，评价进程离线读档案，显示进程读业务状态和独立捕获器。禁止显示/评价向业务注入高速传感或真值。孪生运动只由捕获到的实际 PWM、RUN/FAULT 更新；一旦捕获停更超过250ms，保持位置并显示失联，不靠上一命令无限积分。PWM到虚拟角度/速度的映射写入版本化场景配置，不能宣传成真实钻头动力学。

AI 主任务三类：正常、风险代理、观测不足。窗口取最近8份摘要（约32秒），每份包含8个统计量、4个有效性位、年龄和GAP，共14通道；固定形状张量 `[1,14,8,1]` 的小 CNN，使用基础 Conv/Relu/Pool/全连接，量化前查算子支持。首8窗不足时显式掩码/预热，不能零填后冒称观测完整；紧急本地事件不等待AI窗口。规则阈值是必须有的对照，模型只给有限动作表（保持、虚拟转向档位、停止）。低置信、数据陈旧、输入不合法默认保持/停止；阈值在验证集冻结。

台架按整次采集和未见场景分组，至少训练/验证/测试三组，各组不同采集场次，预处理和INT8校准只用训练集；测试集一次冻结。FORCE只作为公开井曲线编码及岩性回放的独立研究，整井划分，不混作台架风险训练数据。[FORCE 原始仓库](https://github.com/bolgebrygg/Force-2020-Machine-Learning-competition)。

## 5. Agent 自动推进合同

任务图见 [tasks.json](tasks.json)。每卡执行器提交 `operation_id/task_version/code_commit/input_hashes/commands/tool_versions/exit_codes/logs/artifact_hashes`；状态只用 not_run/running/passed/failed/blocked。主质量模型负责决策、关键评估和验收，DeepSeek可承接有边界的执行；不自动授予任何子任务新权限。

依赖通过后可按已授权实施范围自动推进；纯软件失败最多两次有依据的局部修复，每次保存原失败日志，仍失败则提出最小改动并冻结受影响卡。没有变化不重复测试。实板/驱动/未知副作用失败不自动重放，A先核现场和原operation。等待由常驻程序处理，不循环唤醒模型。人类仅完成必须的接线、本人登录/许可和获准付款；当前无需新的细节询问或采购确认。

现有 A 独占的 automation_contract 不修改；本任务图是 C 方案的依赖描述，可由未来实施主会话映射到既有合同。没有制造第二个控制器、任务调度器或三机终验要求。本轮在 GitHub 与飞书完成交付后结束。
