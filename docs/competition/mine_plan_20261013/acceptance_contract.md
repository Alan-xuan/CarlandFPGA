# 每步输入与复核补充

下列输入是任务书第9节的明确执行契约。每步输出保存原始命令、版本、退出码、日志与SHA-256；验收矩阵所有步骤仍为planned。

| --- | --- | --- |
| G0.1 | 本机真实库存、PC/板卡/工具发现输出 | C |
| G0.2 | 人类要求、三机全部候选、内评、最佳封存文件与SHA-256 | C(收三份后逐模块外评) |
| G0.3 | G0.1库存与G0.2统一方案、物理成功/失败定义草案 | C(复核成功/失败定义及危险余量) |
| G1.1 | 授权原始数据包、许可、单位和井号/场次元数据 | B(复跑分组划分) |
| G1.2 | 已冻结接口草案、数据量程、E集合和边界激励 | B(按整数推导核对) |
| G1.3 | G1.2黄金模型、板卡原理图与时钟/复位清单 | C(校验包和参数事务) |
| G1.4 | G1.1至G1.3产物、证据schema与正负验收样例 | B(在新目录复跑) |
