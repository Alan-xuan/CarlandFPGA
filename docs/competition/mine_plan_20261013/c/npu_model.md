## 1. 候选定位与明确取舍

保留原稿“井下 FPGA—受限上行—井上 AMD AI—下行参数/执行机构”的主题，将作品重点改为：**在极低带宽条件下，优先保住决策所需的信息与异常，AMD AI 给出可审计的调整建议，FPGA 在明确约束内执行真实桌面装置动作，传感器反馈证明动作发生。**

参加 AMD Ryzen AI PC + AMD FPGA 方向，以三项能够独立验收的证据争取竞争力：受限带宽下的任务质量；AI 实际改变遥测/动作的消融实验；可重复的实体反馈与异常停机。获奖可能性是选择依据，无法预先保证。NPU 是本方案的特色目标，**并未据此认定官方赛道强制使用 NPU**；赛制和参赛资格由总任务书另行对照官方当届规则。

## 3. 系统与接口冻结方案

### 3.1 职责与硬件边界

```
真实模拟传感器/反馈角度 → ADC → PYNQ-Z2 PL
  ├─ 100 Hz 采样、时间戳、阈值保护、100 Hz 原始记录
  ├─ 1 Hz 趋势/峰值/事件 → 独立块预测残差 → CRC/序列号 → 限速串行
  └─ 指令状态机 → 受限 PWM/方向输出 → 实体单轴装置 → 角度/电流反馈
                                      ↑
AMD Ryzen AI PC：CPU 解析/解码/质控 → 小 CNN(NPU 优先) → 置信门控/有限动作选择
  ├─ 曲线、事件、解释、推理/链路/反馈日志
  └─ 带版本与寿命的参数/角度指令 → 下行 → PL 检查与 ACK → 实测反馈
```

PYNQ PS 负责配置、原始记录和测试注入，不负责绕过 PL 直接驱动执行机构。PL 保持独立本地保护。原始记录可走 PS Ethernet/SD，但必须在评测模式下与限速的“任务数据通道”区分；PC 模型不得偷偷读取旁路原始数据。评测日志记录两个路径的开启状态；断掉旁路后核心演示仍应工作。

ADC 首选已持有、能够在 PL 接入的 3.3 V 数字接口模块。若无合适模块，MCP3208 是低复杂度候选：4 路任务传感 + 1 路机械反馈 + 1 路电流/安全输入，其余留空；12 bit 打包进 16 bit 存储。采样目标是每通道 100 Hz，轮询采样不是同步采样，记录各通道采样偏移；不得声称 AD7606 同步性能。物理机构仅一轴：低压舵机或已有电机台架，机械耦合电位器/现有编码器给出独立角度，另加限位/急停输入。必须在 D1 冻结实际器件、量程、驱动、电源、安装范围及接线图，不能把“舵机 PWM”当角度反馈。

真实桌面传感通道定义在 D1 按库存冻结；可选择力/压力、运动反馈、电流、人工可调电导/光强代理。公共地质曲线与这些桌面通道具有不同物理含义，采用**不同模型与不同单位配置**，不能将旋钮电压输入地质模型后称为真实地层识别。

PL 50 MHz 单主时钟先实现；外部串口/急停做同步和去抖，ADC 接口按选定时序约束。PS AXI 时钟与 PL 不同时使用厂商异步 FIFO/CDC 模块并同步释放复位；复位任何单侧都必须丢弃未完整块、增加 session ID、等待 FIFO busy 结束，不能接续旧预测状态。

### 3.2 编码：保守的有界残差，而非神经解压

每个块独立含 session、seq、基准时间、codec/quantizer 版本、缺测位图、第一点原样基准和 CRC。首版各通道一阶闭环差分：编码器用上次**已重建值**预测当前值，量化残差，解码器同样重建；量化步长 q=1/2/4/8 的整数候选，最大误差按逐点测试和饱和规则验收。残差超范围则逃逸为原样点；块结束后清状态，丢一块不会污染下一块。二维/神经预测器不进入首版解码关键路径。

可选固定 AR(1)/二阶预测只在与一阶基线比较证明收益后解锁；系数为定点整数、版本内固定、限制范围、编解码逐位一致。NPU 的“模型辅助”体现为在经过验证的模式表内选择 q/通道优先级/事件采样策略；不是通过下行传大量神经权重，也不是让 NPU 猜丢失数据后装成实测。

模式表最少三档：SAFE（q=1，事件优先，动作停止或维持）、NORMAL（q=2/4，趋势均衡）、DETAIL（关键通道 q=1，低优先级趋势减频）。每档都受 token bucket 与突变保留约束。若 AI 不确定、CRC 错误、数据龄超限或参数未 ACK，继续 SAFE。默认模型只建议，PL 是有效参数的唯一执行者。

### 3.3 信道与控制协议

300 bps 是本候选为了复现原主题的压力测试条件，不是已查证的真实矿井普遍带宽。优先用 3.3 V 串口 + 实际串行限速，若现有 USB 串口桥不能稳定 300 baud，则保留 9,600 baud 物理速率，在 PL 以真实线路位/token bucket 限制 300 bit/s 并标注“带宽受限信道仿真”；不可标注“真实 300 baud 电缆”。RS-485 只在现有收发器和接口顺利时解锁；不新做电力载波。

初版 UART 8N1 按每字节 10 个线路位计算。固定帧头 11 字节预算（同步 2、类型 1、seq 1、tick 2、payload 长 1、模式 1、两时刻缺测位图 1、CRC16 2）；session/详细配置在链路建立帧中发送，并绑定当前会话。常规块每 2 s 发送 4 通道×2 点：原样载荷 12 字节，23 字节帧=230 线路位=115 bit/s；差分常见载荷 8 字节时 19 字节帧=95 bit/s。实际位流若采用转义必须计最坏扩展开销；首版固定长度/严格长度解析避免转义翻倍，重同步逻辑必须经随机位翻转验证。

正常预算：常规 115 bit/s + 指令总帧 20 字节/6 s≈33.3 bit/s + ACK总帧 16 字节/6 s≈26.7 bit/s + 事件/健康预留 60 bit/s + 仲裁/余量 30 bit/s，总计≈265 bit/s，小于共享 300 bit/s。这是设计预算，不是测量；事件暴发时减少/丢弃低优先级趋势并准确显示缺点数，不能使队列无限增长。10 秒和 60 秒窗口内包括启动位、停止位、ACK、重试、配置的平均总线用量≤300 bit/s；若 300 baud 串口满速瞬时发送，另明确突发持续时间与空闲比例。

事件可以在当前趋势帧结束后优先发送：最坏非抢占阻塞约 0.767 s，含一字节事件载荷的12字节帧约 0.400 s，加 100 Hz 检测≤20 ms，设计事件首包到达≤1.2 s，台架验收 P95≤1.5 s（从硬件事件触发到接收完整 CRC 事件）。普通趋势数据龄 P95≤4 s。远端动作回传若需指令/ACK/机械响应，设计 P95≤5 s，不能宣传“毫秒级井上闭环”。本地急停无需等待链路，PL 检测到输出禁用≤20 ms。

控制帧须有 cmd_id、mode/angle、有效期（接收时本地 TTL）、参数版本；包序号回绕与新会话明确。PC 等 ACK 不等于动作完成；动作完成必须由角度反馈达到容差并持续规定时间证实。CRC 只抗偶发错误，不能宣传抗恶意攻击；台架串行受信连接，无需三周内引入加密复杂度。

原始保存预算：8 路×100 Hz×16 bit=12.8 kbit/s=1.6 kB/s，10 min 数据约 0.96 MB（未计时间戳）。64 KiB BRAM FIFO 是约 41 s 的**理想纯样本**缓冲；实际记录时间戳/状态后更短。PS DDR/SD 负责持续落盘，PS 停顿只可保证明确长度，不承诺无限断连缓冲。FIFO 满明确计数并生成溢出事件，不静默覆盖。均值/极值提取后的数据约 1 Hz，不得把 100:1 降采样写成无损压缩率。

## 4. 模型、解释、数据与防泄漏

### 4.1 两个有清晰边界的模型任务

**G 模型：地层辅助回放。** 使用 FORCE 原始资料中的 GR 与另外最多三条实际可用曲线（例如 RDEP/RHOB/NPHI）和缺测掩码，按深度顺序预测岩性或已标注岩性变化，展示对压缩误差的敏感性。石油海上井数据与煤矿域不同，标题标“公开历史测井回放/岩性辅助”，不把砂岩认定为含水层，不把岩性边界认定为断层，不展示未来深度作为实时可获知输入。煤层类别样本不足时仍报告该类别指标，不为了高分重标/删除测试井。

**D 模型：实体台架工况。** 在 D1 确定的真实传感器上收集正常、卡滞/限位、异常负载、传感断线/漂移等能够安全复现的工况，标签来自独立装置状态/反馈和日志。模型输出“正常/疑似异常/拒识”，可改变趋势优先级、q 档或下发小角度安全动作；不输出矿井灾害概率。强故障由 PL 硬阈值保护，模型增加早期告警和资源分配，不替代急停。

不强迫两任务共享权重。两任务复用训练/推理代码与数据契约，分别有 model_id、单位表、checkpoint、数据清单和模型适用域。比赛展示一套物理台架闭环，旁边切到公共数据评测页；屏幕明确来源，不拼成“矿井实测”。

### 4.2 1D/2D CNN 与经典基线的独立选择

逻辑首选因果 1D CNN：输入过去 T=32 点、4 通道及缺测 mask；每 2 s 新块触发推理，历史窗口已有数据时无需再等 32 点，启动前显示 warm-up。卷积通道 16→32→32，核 3 或 5，简单 ReLU/池化/线性头；目标参数≤100k、batch=1 固定形状。模型大小并不自动带来 NPU 加速，小模型可能 CPU 更快，必须公平测量。

NPU 编译候选用 `[N,C,1,T]` 的 Conv2D 及 `1×k` 核表达同一逻辑 1D 运算，先在 CPU 上逐点比对，再看具体图是否能完整分配 NPU。此转换**不是已证明可部署结论**，高度为 1 可能受后端限制；失败后测试明确且等价的 reshape/padding 方案，不为了能编译把通道乱排成有虚假平移含义的图像。一般 `[通道×时间]` 图像式二维 CNN 不作为首选，因为不同物理通道互换并不等价；二维地质剖面 CNN 需要当前没有的真实空间标注。

经典基线：G 任务用多数类/线性逻辑回归/树模型，输入相同过去窗口的统计与缺测 mask；D 任务用 PL 阈值+滞回、CPU EWMA/CUSUM 与同窗树模型。对比 CNN FP32 CPU、量化 CNN CPU、同量化模型 NPU；所有模型使用相同测试数据、因果上下文、压缩版本。经典模型不能为了突出 NPU 故意采用弱参数。CNN 的采用条件是实测任务效用或能效有收益；若不赢，保留基线为实际决策者，NPU 仅明确标为研究对照，竞赛卖点评分必须下调。

解释采用：原始/重建曲线和误差带、缺测位图、当前模式、风险理由（具体通道/阈值）、小规模通道遮挡贡献。遮挡解释为模型相关性，不宣称地质因果；每 5–10 s 在 CPU 进行，避免大量反复 NPU 推理拖慢核心。置信阈值只在验证集校准；低置信和域外输入必须拒识。短时趋势预测是模型估计，单独虚线显示，绝不能标实测曲线。

### 4.3 数据与标签泄漏防护

1. G 数据按 WELL 划分训练/验证/最终测试，名单与哈希 D2 固定；不能随机拆相邻深度。每次用于编码选择、标准化、填补、量化校准、阈值校准的样本均只来自训练/验证许可范围。公开 blind 标签若已可取，仍可预留一组未看结果的测试井，不称官方盲测成绩。
2. 因果窗口只到当前深度；不使用未来点双向平滑、对称窗口或整口井插值。缺测填补使用训练统计与 mask；井名、X/Y、最终地层解释、岩性置信标签不得进推理特征。训练标签置信可作为训练权重，但不能成为推理输入。
3. D 数据按独立采集 session/day/operator 分组；同一段切成窗口不能跨 train/test。真实故障事件重复至少多个 session，台架旋钮动作脚本、标签和模型输入分别记录，不能把注入编号/动作信号泄漏给模型。合成噪声单列，不能补成真实故障样本数。
4. 全部压缩/模型调参完成后只跑一次锁定测试；若失败并据此改参数，将该集降为验证并另留新 session/井。原数据、过滤规则、单位、标注来源、缺失统计与许可证保存清单。
5. G 数据无法获得明确灾害标签时只验岩性，不临时按电阻率阈值自动生成“含水真值”并据此宣布有效。D 的离线模型不使用最终测试 session 量化校准。

## 5. AI 真实参与和物理闭环

每一动作日志关联 `input_block_seq → model_id/hash → provider/运行证据 → logits/confidence → rule reason → proposed mode/angle → cmd_id → PL ack → 实测 angle/current → result`。用于实际决策的推理必须记录输入哈希，关闭旁路输入。NPU 本轮实际不可用时显示 CPU provider，不能保存假 NPU 标签。

NPU 验证至少包含：官方 quicktest/同类 CNN 案例通过；本模型的 compiler 算子分配报告中存在实际核心 Conv/Gemm 在 NPU；AMD AI Analyzer/运行日志与连续推理记录；CPU-only 同一模型对照。按 S1 用 `XLNX_ONNX_EP_REPORT_FILE` 生成分配报告，必要的 CPU 预处理/输出节点允许保留，但必须列出；仅 Task Manager 截图不作为充分证据。冷编译、热加载、稳态 P50/P95 分开报告，固定 batch=1，不把大 batch 吞吐当控制延迟。目标稳态单次 P95≤100 ms；最迟 D3 验证，失败则降级仍可交付但 NPU 加分不成立。小 CNN 可接受 NPU 比 CPU 慢，只如实展示；不得承诺必然加速或节能。

AI 参与动作至少两种可复验因果差异：A）出现疑似边界/异常时将关键通道切 DETAIL、降低 q；B）正常稳定时选择 NORMAL，减少线路占用；C）若台架验证充分，可建议±5°单步角度，在 PL 当前允许区间内执行。选择 A/B 作为必交，C 为物理演示有价值但建议范围可因台架变化冻结。规则预先写死的动作不能冒充 NPU 生成；必须做禁用模型输出/固定建议对照。

实体演示过程：人工施加安全可重复负载/传感变化 → PL 上报事件/趋势 → 模型输出及置信门控 → 参数/小角度动作 → PL 检查 → PWM/驱动 → 独立角度反馈变化 → 回报达标或超时。单轴限角初定±20°、单步≤5°、速度≤10°/s，具体值由实际机构 D1 冻结。反馈误差>5°持续1 s、限位、过流或本地急停立即锁停止；解除必须人工确认。PC 无响应/指令到期默认维持安全角并停止继续前进；绝不为了恢复演示自动解除故障。

模型不确定和地质回放中的“疑似危险”只能提出停止/减速或请求人工复核；在未建模的真实地层中自动绕行不属于本候选承诺。3D 画面由实测反馈驱动、显示模拟地层，不能用目标角度驱动画面后当作反馈成功。

## 8. 评测、演示和落地收益

评测组：①未经压缩的1Hz参考（只用于离线任务质量）；②固定保真q/原样逃逸；③简单阈值自适应；④AI模式选择；⑤同模型CPU/NPU。每组报告线路位（含协议）、曲线最大绝对误差/归一化RMSE、事件漏报/延迟、任务macro-F1、重试数/丢包率、FIFO高水位、推理时间与动作成功率。峰值/局部梯度另外报告，不能用全局RMSE掩盖突变。采集高频原始与1Hz重建分别画，不做错位对齐来掩盖延迟。

“比CPU省电/更快”只在实际仪表/统计测量支持后写入。统一同设备电源模式、相同模型精度、相同输入/批量、预热200次、稳态至少1000次；功耗如只有整机插座仪表就标整机能耗、不标NPU芯片功耗。三周测不到可靠能耗时只给时延和CPU占用，不编造能效。

六分钟演示建议：前1min交代真台架/历史资料/受限信道；第2min固定模式显示带宽与信息损失；第3min注入安全异常，AI切DETAIL保关键通道；第4min实体角度反馈/急停；第5min断链和CRC故障恢复；第6min一键显示同输入消融和NPU实际执行证据。展示界面四块：趋势+误差带；码率/事件队列；模型依据+运行设备；目标角/实测角+FSM。传感数据来源醒目标注，结果语言朴素可信。
