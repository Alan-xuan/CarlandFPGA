## 逐部分评析与改进

C1的编码/事件主线最易在三周实现，但事件风暴、未发送区间误差和本地缓冲需要改进。吸收C2的包络和数据年龄展示，细节只在剩余预算中补传；不把完整渐进编码加入关键路径。低带宽趋势被抽样，量化误差界只针对真正已编码点；未发区间另报包络、丢点/年龄。

C3给出CPU严格解码、NPU图分配实证、缺测mask和置信门控，予以融合。AI控制仅在有限动作表内，拒识或数据老化时停止/保持，不回传神经权重。小模型NPU可能不如CPU快，必须公平测试；NPU是特色目标，不伪称官方必选。

C4保留独立块、raw旁路、完整本地档案与确定性PL保护，修补C1在噪声、丢包和断链时的弱点。raw块可能超在线预算，应降低趋势频率而非把不可压数据塞入无限队列。档案数据可慢传或现场导出，不宣称全量实时通过300bps。

C5的重建复杂度、稀疏性及位宽风险不适合三周主线；吸收其域外/非稀疏/窄脉冲测试和不确定性监视，压缩感知不作必交。

对抗评审建议旋转负载台架，可提供真实物理扰动和反馈，是机械资源不足时的保底。主选仍保留随钻导向主题：低速推进加偏转/探头对准安全通道，实际传感与实际位置反馈。若只有电机加载装置，采用“随钻工况异常降速/停钻”实物闭环，并将地质曲线回放明确作为第二条分析证据。10月14日库存确认后冻结一种实物任务；不能同时建两套台架。

## 改进后的C最佳案

题目候选：矿脉深瞳 基于Ryzen AI与PYNQ Z2的低带宽随钻感知和实物闭环验证。

主链：PL时间戳/质量/事件→有界差分Rice及raw旁路→优先队列→真实限速双向链路→CPU解码→端侧小CNN与置信门控→受限命令→PL状态机/PWM/限位→真实位置或转速反馈。PS承担档案/DMA，三维图仅镜像实际反馈。高频采样、慢变遥测、完整档案三者分开。

300baud 8N1半双工预算候选：每8秒240线字节，遥测90payload+两帧32头，指令24、反馈20、告警20、guard总0.2秒；合计6.4秒占80%。四通道2Hz16bit摘要128原字节需载荷比≥1.422，噪声时1Hz保底。该预算已由check_budget.py核算，未做线测；具体帧字段/仲裁由统一方案再冻结，禁止拿各候选不同帧格式混算。64字节最大普通帧会阻塞2.133秒；无竞争/重传告警预算3秒。下行调度需预留及时命令窗口，8秒只是计量窗口，不强制8秒才响应一次。

正确性：至少百万样本逐位对照；有界编码已传点误差≤E，无损E=0一致；丢包从下一独立块恢复；FIFO满/坏CRC/复位/重复/回绕有证据。实现100MHz候选、WNS≥0、完整XDC/DRC/CDC；无工具状态blocked。实体A独占操作。

AI证据：固定形状小CNN，CPU基线和实际加速后端，模型哈希/驱动/算子分配/ORT日志；FORCE按井、台架按采集场次分组，训练预处理不看测试。公开岩性raw Macro-F1初始目标≥0.60；压缩后绝对下降≤0.03；代理实体任务另设指标，不宣称含水识别。使用模型输出追踪真实动作，做AI关闭消融。

实物与验收：台架10月17日前固定基线闭环；30盲布局×3次/关键配置，目标成功≥90%，所有停止/侵入/干预记失败或独立指标并预定义；30分钟真实链路稳定运行。数字限位逻辑候选≤2ms，100Hz采样异常候选≤20ms；实际制动另测。远端完整响应候选≤5秒，推进≤2mm/s、前视候选20mm，最终用实测延迟/误差/制动校验。

阶段：10/14资源与三机外评；10/15黄金模型/协议；10/17实物基线；10/20编码可靠链路；10/23AI；10/27集成冻结；10/30盲测；11/1复建与材料；11/3内部提交，11/4 18点公开截止。未确认AI PC/执行器通过群询问。三机候选分工A物理/总集成、B编码与实时RTL、C协议/数据/模型/验收；有Vivado节点构建，C本轮preflight未发现Vivado。
