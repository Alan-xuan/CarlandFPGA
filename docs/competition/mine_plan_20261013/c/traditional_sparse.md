# C 机独立候选四与五

任务 MINE-20261013-PLAN-C，版本 1，负责人 C。以下是设计候选和假设，尚无压缩、NPU或板卡实测。未联系 A/B，也未读取其本轮方案。

## C4 无损档案与确定性安全导向

目标：以可解释、可重建的 FPGA 传感压缩和本地安全状态机形成低带宽导向闭环。采用 PYNQ-Z2；PL 完成采样时间戳、预处理、块差分、Rice 编码、原样旁路、CRC、优先队列、UART和运动安全；PS只负责归档与应用桥接。井上 Ryzen AI PC 的 CPU 解码，NPU小型卷积网络估计岩性边界概率，CPU受限规划器产生舵机目标。执行机构实际位置经编码器回读到PL，驱动下一轮观测。

传感两层：桌面光学或电学代理传感器提供可重复实物信号；真实公开测井曲线通过固定重放入口测试编码和模型。代理信号不叫真实GR或含水层测量。主站不得直接读取执行装置全分辨率数据、真值地图或原始重放文件；它只得到计费后链路数据。评价程序可另读真值。

算法：块首样本为绝对锚点；残差用明确宽度的有符号运算与zigzag；遍历有限k选最短Rice码，限制商长度，超界用escape或整块raw。RLE只作为经测试有益的可选模式，不强行串联字典。码长超过raw则选raw，包头标模式、有效位数、块序号和参数版本。每块可独立解码，丢包不会无限污染预测器。离线原始完整曲线保留，不等同低速链路实时传完。

链路设计假设：300 baud、8N1半双工RS485，实际可发送30字节每秒而不是37.5。4通道100 Hz×16 bit采集=6400 bit/s；若全部上送，未计包头就至少需26.67倍压缩，因此高采样率不能自动变为低码率。实时慢变曲线可先按2 Hz生成导向摘要；4×2×16=128 bit/s，此处降采样与压缩必须分别报告。8秒窗口总240线字节，常态目标占用≤192；帧最大64字节、头16、每帧最多48 payload。预留64字节用于指令、反馈和告警；常态遥测可用128线字节，即最多96 payload字节。2Hz摘要原始128字节/窗口，常态至少需要128/96=1.333倍载荷压缩；不可压时改1Hz或延期细节，不丢告警和本地保护。所有重传、转向间隔和填充必须计入线负载。

展示：透明桌面层状地质轨迹台，步进平台推进、舵机改变方向，位置/限位反馈回到FPGA；光学层状材料代表“危险区域代理”，避免要求真实矿井设备。相同未知布局对比固定码率/无自适应、无AI、完整系统的到达率、区域侵入率、停止次数和耗时。数字孪生只显示实测位置，不作为物理执行证据。

验收：10^6样本逐值无损一致；包括随机高熵、饱和、跳变、FIFO背压、复位、坏CRC及丢包；64字节帧传输理论下界2.133秒，任何亚秒端到端声称需另定义本地路径。300baud下台架推进速度先限2mm/s，前视距离至少20mm；局部限位停机独立于上位机。核心同条件盲测至少30布局×3次，未通通过必须保留失败。资源/时序/板测各有原始证据。

优点：硬件贡献清楚，数据诚实，可实现，可复现。缺点：弱信号上无损压缩有限，突变会扩展码长；长块排队影响风险发现；纯无损不保证应用任务最佳。融合：吸收C1的事件优先与误差有界编码、C2关键点优先、C3置信度与模型算子证据。维持C4独立块raw旁路和档案作为最终质量保护。

依据：[CCSDS 121.0-B-3](https://ccsds.org/Pubs/121x0b3.pdf)提供Rice自适应编码参考，拟实现只称受其启发，不声称兼容；[AMD部署文档](https://ryzenai.docs.amd.com/en/latest/modelrun.html)支持CPU/NPU算子分配检查；[TI THVD1450](https://www.ti.com/product/THVD1450)提供3.3V RS485器件资料。数据许可和用途依据[Equinor Volve原发布页](https://www.equinor.com/energy/volve-data-sharing)与[FORCE原数据记录](https://zenodo.org/records/4351156)。FORCE为岩性日志数据，并不能直接提供含水风险或随钻闭环真值。

## C5 压缩感知与自适应重建导向

目标：以FPGA随机投影减少上行量、Ryzen AI PC稀疏或神经重建恢复多通道曲线，再完成实物导向。每通道64点块，FPGA计算固定种子±1投影；CPU运行OMP/TV基线，NPU部署固定展开网络候选；主站风险估计后经低速链路下发推进/方向，本地FPGA保留与C4相同独立安全状态机和执行反馈。

预算：4通道×64点×16bit原始512字节。每通道16投影，每投影24bit，加种子/尺度/包头约208字节；仅2.46倍线前压缩，300baud下需约6.93秒，采集64点若10Hz为6.4秒，尚未含反馈/重传就不稳定。投影降到8个/通道约112字节可改善吞吐，但稀疏假设和风险保真更脆弱。投影位宽还需按64项累加+输入满幅推导，24bit是设计候选，不能假设溢出后仍可重建。

技术重点：固定投影矩阵/种子与尺度版本，有限位宽溢出检测；独立块锚点；重建残差、不确定性与异常监视；带宽不足时先传危险事件，再传投影。数据集分井隔离，测试全新地层、窄脉冲和非稀疏高噪声；先以OMP/TV验证可辨识性，神经网络不能用同井相邻窗口泄漏。量化模型须给CPU/NPU分配和CPU基线，不能假定迭代求解器可直接运行NPU。

验收：每块投影逐位匹配黄金模型；在固定观察延迟/线预算下，危险事件Recall不得比未压缩参考下降超过2个百分点；报告最差窄脉冲丢失率、每井误差和完整闭环成功率。若新井/噪声失效则退回C4；禁止用漂亮曲线遮蔽漏风险。

优点：学术叙事明显，FPGA并行投影与AI重建协同紧密。缺点：依赖稀疏性、定点矩阵误差和域外泛化；块等待、投影开销、NPU支持风险高，未必优于简单关键点。作为备选而非默认主线。可融合其独立不确定性监视、同预算对照与极端脉冲测试，不必引入全部重建复杂度。

依据：[Candès Romberg Tao原论文](https://arxiv.org/abs/math/0503066)的恢复保证需要稀疏性及矩阵条件，不能据此推定真实测井曲线压缩率或含水识别准确率。所有上述数字均为本任务设计推导。
