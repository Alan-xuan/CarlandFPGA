# C42 producer attachment API v1

This package assembles inputs for the unchanged published C36 host-v2 schema. It does not load C36/C28 or make a dispatch. Module initialization reads only the adjacent pinned schema. Exact original modules must already be loaded by A; this package never imports or starts them. The production factory checks their whole-file SHA, exact types, retained owner/link/book/custody relationships and original thread checks. These are trusted-process conventions, not an OS security boundary or authentication derived from labels.

## API and original callsite order

1. `p = attach_original(owner, link, book)`: inside the already existing A108 original owner process, after the original link/book exist. Exact source target51c48e106c76f3e4d18000da61be17dd8a4b6623; no test objects or caller enabled flag can create this binding. The original `link._registered()` and custody `_context()` checks run on attachment/export. Foreign/replaced/failed original references reject.
2. `p.bind_id(original_ref, opaque_id)`: A supplies its existing genuine opaque ID and corresponding original retained object. No IDs are allocated here. The same reference cannot rebind; duplicate labels for different references reject. Bind actual book, binding, composition, link, producer registry/config records, transition, slot, allocated/returned receipt, witness, publication, admitted readback and actual getter-policy object as required. IDs/refs alone do not authenticate observations.
3. `p.attach_config(original_config_receipt_ref, fields)`: one original config association, including actual context/generation/profile/calibration/anchor/goal/counter baseline fields. The assembler inserts only bound IDs for the actual config record/book/binding; it does not infer a namespace from any raw hash.
4. `p.attach_admission(original_admission_ref, fields)`: every retained actual prefix member, with original index/tick/count/quality/wire-source hash/receive time/new-EM flag. Indexes are supplied, never made from list positions. Maximum1001; no trimming or rebinding.
5. `p.attach_capture(original_capture_ref, actual_sample_ref, candidate=original_candidate_document, fields=external_capture_fields)`: after the original source/native receive callsite has retained both objects and left the active source polling/EM scope. The sample must be an identical retained object in original book._samples, not a digest lookup. Native request/capture UTF8 strings must preserve original newline and bytes. Full Candidate fields remain original host/native producer facts. Mechanical ADC/held-EM metadata comes from that actual sample, while native origin-capture hash, wire source hash, source-admission index, pose/span receipt IDs and cause-action relation remain explicit original callsite attachments. No book canonical SHA is substituted for wire source_record_sha256. Retain the original sample token/draft reference at its genuine callsite; do not recover identity from array position. If the callback occurs during source polling, A must retain those refs at that callsite and attach after the original idle fence, without resetting source state.
6. `p.attach_transition(original_transition, successor_root=actual_after_root, slot=original_step_slot_or_none, fields=external_association_fields)`: after original finish_nonspatial/finish_step/_progress_actor_commit has actually completed and cleared pending state. Transition must be retained in original custody; nonspatial successor must be the actual current original Root at this attachment point. STEP slot must be retained in owner._commits and bind the same transition/witness/link. Old successor refs remain retained for later exports; they are not replaced with current Root. STEP candidate/returned/time/command/publication fields come from original slot/witness/receipt, and `_require_admitted_readback(pub, slot)` checks the exact retained A108 frame/time/digest before serialization. Nonspatial BOOT/COMMAND data uses retained after.boot/after.command and actual before/after object identity. Unknown observed custody status/time and external observation/action association stay explicit fields, never clear/complete defaults.
7. `current = p.read_current()`: calls original book.current_pose_interval() exactly once, then book.evidence(), in that order. It retains actual original returned objects, original bytes and span identity. This is an ordered non-atomic read, not a new atomic snapshot guarantee. On failure no retry occurs; this producer latches and raises, preserving original owner resources.
8. At that actual return callsite, A binds IDs for `current` and `current['valid_span']` using bind_id. `p.attach_registry(original_registry_view_ref, context, generation, as_of_qpc_ns=actual_associated_observation)` retains that immutable original view. Up to32 distinct views are retained. It does not replace or renew earlier views. This supplied as_of must equal the actual getter-end observation under the frozen C36 contract. C42 does not invent it, sample a new clock or silently stamp it from getter time. If A cannot supply this original association, keep it unavailable and bring the contract gap to main.
9. `r = p.export(current_read=current, registry_ref=the_original_registry_view_ref, candidate_ref=the_selected_original_capture_ref, history_refs=explicit_tuple_of_original_capture_refs, enabled=False)`: no getter repeat, no sample replay. Original current bytes and span pointer must remain unchanged. Registry/candidate/history selection uses actual references, not latest index/hash guessing. Retained full capture/admission/action data remains bounded; it is never trimmed to fit. Maximum32 capture/action/current/registry entries. Original source evidence input<=16MiB, schema-projected request<=1MiB. The larger private source budget permits discarding non-schema payload/canonical hex without dropping history. Exceeding bounds rejects.

## Result and incomplete evidence

`partial` always retains mechanically available whitelisted schema fields even when one required attachment is missing. `missing_paths` names absent supplied fields; `dropped_paths` names discarded source fields without their values. Missing local attachments do not imply the original producer lacks the facts. `proof=None` when required fields/receipt bindings/current data or association coverage are missing. No placeholder config, opaque ID, fresh time or successful receipt is made.

If `proof` is supplied, status is only ASSEMBLED_UNVALIDATED. This is a finite assembled input, not a valid/authenticated C36 proof. A must still pass it through exact reviewed C36, preserve full original provider provenance and then follow C41/C40 custody/correlation rules. JSON presence, enabled=true and labels grant nothing. Every result keeps source_authenticated=false, dispatch_authorized=false, core_ran=false. `live_owner_binding_checked` reports only those local identity checks, never full source/native authority.

The pure `assemble_snapshot(evidence, current, attachments, candidate=..., history=..., enabled=False)` is an untrusted diagnostic path. It cannot instantiate a live producer. It does not call a getter; callers must not label supplied snapshot data as live. Software tests use this path and explicit fake receivers for isolated method mechanics only.

## Exact field provenance

- Book schema3/state/source_state/origin/samples/old_pose_span/closed spans/pending/current interval are projected from actual original evidence with a whitelist. Snapshot SHA is over the original detached evidence before dropping private fields and is consistency-only.
- Book current_read is exactly the genuine getter return; root Current pose/revision/at/bracket/span endpoints are copied from it. Root revision comes from that actual span. Receipt IDs/context/generation are separate original provider bindings. Interval-only exports cannot supply this read. Supplied Root/span/end contradictions reject even when other attachments are missing.
- Original ADC six-field completion metadata and pose reads retain exact integers and nulls. Held EM pose/read/call/scope/span remain the original held observation, never the later ADC/current pose. Native capture association and original opaque receipts remain separate.
- STEP start/end and command fields come from the retained CommitReceipt/command bytes; candidate and returned IDs require bound references. Publication uses retained operation/state/digest/freeze/revision and immutable admitted_readback_ns/frame identity. No exact CAS time is synthesized.
- Actual slot.endpoint_bounds and binding.world_values.budget_derivation.getter_endpoint_cap_m are exported only when exactly representable under the frozen JSON-number schema. int/finite float values are retained; integral Fractions become exact integers; other Fractions require exact float round-trip equality. A nonrepresentable Fraction yields missing at publication.local_error_bound_m/global_error_bound_m/frozen_getter_cap_m; no rounding into a smaller proof bound. Synthetic1/10 is a demonstrated possible representation gap, not an observed real A runtime value. Any unresolved producer contract amendment belongs to main/A; the C36 schema is unchanged.

`producer-attachments.json` contains every frozen field table and marks mechanical fields versus original external groups. The implementation provides no new original callsite hooks in A files. A must wire the exact hooks above and supply real opaque bindings; this is an explicit remaining integration dependency, not software acceptance or physical proof.


## C42-R1 repair: original identity and wire completeness

The frozen C36 schema deliberately permits null to represent unavailable evidence. Representability is not attachment completeness. This repair adds explicit checks for `request.root_receipt.config.pose_book_id`, `request.root_receipt.config.owner_binding_id`, and each `request.root_receipt.captures[i].request_raw` / `capture_raw`. A missing or null value yields INPUT_UNAVAILABLE, proof=None, and that exact missing path. A null capture record reports its indexed path. Other mechanically supplied partial fields remain unchanged. These checks also apply with enabled=false.

Source of these rules: unchanged C36 A108-v2 host_projection.py lines 353-365 explicitly requires config receipt_id / pose_book_id / owner_binding_id and both capture wires. Existing receipt_id completeness remains in C42's receipt scan; required nonnullable identity/hash fields remain checked by schema projection. Producer.export derives config binding labels only from the original book and link.binding reference registry. Producer._capture now preserves explicit null wire as unavailable; nonnull non-string wire still rejects. It never generates a wire or substitutes a canonical book hash for it.

This is deliberately field-specific. BOOT's absent command_receipt_id/command_seq/command_sha256 remains allowed by the existing kind-aware rule. No-EM fields, invalid channel values and a null cause_action_id are not blanket forbidden. The no-EM adjacent control tests this assembly null policy only; it is not a complete C36 semantic/wire/quality fixture. Full conditional capture/source/transition validation still belongs to unchanged C36. ASSEMBLED_UNVALIDATED is neither a valid proof nor an authentication/dispatch grant.

The five new independent-review cases were replayed against the copied baseline: one complete case passed, four missing-original cases failed (run01, exit1). Repair run02 passed those five plus three narrow adjacent controls: absent-key/null-record handling, Producer._capture null versus wrong-type wire, and no-EM nullable field preservation. No old suite, original source execution, C36/C28, model, PDE or board operation occurred. All controls use explicitly synthetic data; complete assembly proves the output path is reachable, not original provenance.


## C42-R1 v2: ADC and conditional EM original-attachment presence

The v2 repair adds a finite presence/link check after unchanged schema projection. It does not execute or copy the C36 semantic engine. Its static source is frozen C36 A108 host_projection.py: _receipt (439 onward), _captures (458 onward), and the nonempty admission requirement (383). The C36 runtime remains SHA256 7defaee9318f9a33a0586628661d054c028b5952584030ebc3b771a479a8982e; request schema remains ab1b432e9f337523fd75057fec4647f5eda2569de308e7c777507e05907bdd70.

| Scope | Availability required |
| --- | --- |
| Source prefix | source_admissions must be nonempty; this does not validate prefix ordering, contents or freshness |
| Selected candidate and history | Each supplied observation's capture_sha256 must resolve to exactly one supplied capture; no array-position matching |
| Every supplied capture | adc_call, adc_root_revision, adc_pose, adc_book_source_sha256; ADC book source SHA resolves to exactly one actual supplied sample |
| ADC pose receipt | receipt_id, pose, pose_revision, pose_read, valid_span; existing nested receipt scan and schema check retain exact missing fields |
| Original ADC sample | adc metadata, numerical_pose_span and pose_reads.adc present |
| EM condition | Any matching supplied candidate/history observation has source_time.em_tick_ms != None. No quality flag or caller boolean grants an EM association |
| EM required capture fields | em_pose, em_root_revision, em_book_source_sha256, em_origin_capture_sha256, original_em_call, original_em_scope_closed_qpc_ns |
| EM original links | EM book source SHA resolves to exactly one sample, EM origin capture SHA resolves to exactly one capture; original sample EM read and ADC sample held_em_association.original_em are present |
| EM receipt and held original | Receipt pose/read/span fields present; retained original_em pose_read/call/numerical_pose_span present |
| No EM | The six EM capture fields may remain null. No original EM sample or held association is generated. Conditional equality/contradiction checks remain C36's responsibility |

Missing scalar/object fields report their exact request path. A missing or non-unique target reports the original association field path (e.g. captures[i].adc_book_source_sha256), retaining its supplied value in partial. Missing selected captures report candidate/history.observation_identity.capture_sha256; an orphan supplied capture reports its capture_sha256 path because its EM condition cannot be established. Ambiguous links are never selected by position. No proof is produced when any such availability path is missing.

These are availability checks, not complete C36 validation: matching labels or hashes do not authenticate their source; time/pose/revision/quality/calibration/raw-wire coherence, admission semantics, state transitions and dispatch eligibility remain downstream. Duplicate/conflicting facts may be diagnosed unavailable here and still require C36's structural rejection. ASSEMBLED_UNVALIDATED means finite assembled input only. Local missing attachments do not prove that A's real producer cannot supply the facts.

New v2 evidence: run01 preserved the copied v1 behavior with 19 failing subcases across the ADC/EM checks and two passing positives. The first failure in the original-book association method prevented its later branches in that pre-fix run; no claim is made that those later branches individually failed then. run02 separately preserved the new empty-prefix failure. run03 passed all eight v2 methods, including their directly related subcases, complete ADC/EM assembly and no-EM assembly. Existing R1 groups and old suites were not replayed. No C36, C28, original A runtime, model, PDE or board operation occurred.
