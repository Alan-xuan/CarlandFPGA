# Root-only receipt preparation API, partial v2

All calls run in the original Root owner thread. This is trusted library composition, not an IPC or controller-input interface. Python object privacy is not a security boundary. No arbitrary callback, registration of a class, `verified=True`, hash or caller JSON creates provenance.

1. In the original AuthorityConfig, select `g05p_profile=G05Profile(policy_raw=actual_policy_file_bytes, enabled=True)`. False is the default. Policy bytes must match the actual SSH ready observation's `policy_file_sha256`; C48 also checks their internal digest and operation binding.
2. A creates the actual world/session/chain and original init with its unchanged producer or `prepare_pre_source_cycle`. Actual `OriginalG05OperationBinding` receives this same config plus the original two contexts. Neither context is inferred from the other.
3. Call `attach_original_operation(config, original_operation_binding)`. It checks exact published types, calls original `_check`, and stores a nonreplaceable local relation. This is needed because A's binding is allocated after the config and init, avoiding an impossible cyclic constructor argument.
4. For this **receipt-only partial slice**, call `production_channels(config, original_world.source.link, original_world.clock)`. Despite the legacy factory name, this only prepares the channel; it performs no actor acquisition. It consumes the original `claim_for_factory` once, including failure. It cannot later be transferred into another authority factory. Real init is consumed from original producer history by opaque event identity, not a copied receipt/dict.
5. `retain_status(original_event)` consumes pending source admissions first, validates a real status/apply result using C48, and returns `(DetachedFacts, OriginalPhaseReceipt)`. It does not allocate a G05Health or session binding. Current tested/independently usable scope is init/status; apply must wait for C48's separately reviewed capture-domain correction.
6. `pump_pending()` calls only the original producer's fixed `pump_once()` on the same thread and consumes its **returned tuple**. That tuple already drained the producer's pending list. It then consumes any separately pending events. It never dispatches AI per source admission. Callers must not drain and discard the tuple before passing it here.
7. After original source start and actual C42 config attachment, A invokes original `binding.attach_source_config(actual_original_config_ref)`. `retain_trace(event)` calls `check_source_config()` and consumes earlier source events before the TRACE phase. It returns a distinct `TraceObservation`: original binary `raw`, request bytes, companions, source/phase/event refs, exact lane counts/flags and conservative nominal source lower. It returns no C36 proof/public AI input or authority grant. Its `boot` is None when no actual actor binding exists.
8. `retain_failure_event(original_event)` permanently revokes the channel and consumes the actual failure event for evidence only. It does not run the live-health path. Cleanup/close remains solely with A's original owner; no retry or external side effect is performed by this adapter.

The original `ActorComposition._production_channels` calls `require_activation_ready()` before these steps can acquire an actor. It rejects this partial integration. `verify_boot`, typed health gates and expanded original type gates are prepared source for the future closed path, not evidence that it has been reached in production. The new local activation `generation` is allocated from the original executor counter; it is not a board session, tag or native generation.

No BOOT_ACK or STATE8 is invented. No G05 binding subclasses/wraps legacy BootBinding. Host PhaseReceipt identities are checked against the original host chain/transport; no host object is compared by Python identity with a remote board issuer. Board issuer/device custody remains in A's original board ledger and corresponding original raw IO.
