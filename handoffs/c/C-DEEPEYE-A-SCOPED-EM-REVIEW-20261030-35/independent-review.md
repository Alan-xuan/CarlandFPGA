All line references below are one-based in the immutable inputs/candidate-* files (or explicitly named dependency files), not a claim about a moving checkout.

The successful profile snapshot includes original value and saturation tuples.

It checks numeric span coverage for original nominal/read/call/closed times. This is a bracketed numerical association, not an atomic native sample or physical measurement.
- Original ownership: root_source_book.py:93-163 and184-279 check exact production Root/book/source/profile/field types, retained owner/native/QPC associations, original thread, frozen binding, source clock, actual renderer/root pose and revisions. Software fixture construction is separated and cannot adopt a real native owner. The same-process private-object protocol is not an OS/security authentication boundary.
- Progression and held preservation: root_source_book.py:508-529 matches the ADC record to the original successful EM receipt by tick, values, quality valid/held bits and saturation bits. The held association carries the earlier receipt rather than assigning current pose/read/call as the EM origin. New success assigns a new receipt object; previous completed samples retain their earlier object. evidence():620-639 serializes a detached copy. A failed acquisition clears the latest usable receipt; producer source-fault records do not resurrect older held evidence.
- Failure: root_source_book.py:38-58,593-618 and causal_pl_exchange.py:298-304 fail the book/source on exceptions and prohibit retry/reuse. A partially consumed slot is not rolled back. The failure path does not turn a partial scope into a completed receipt.
